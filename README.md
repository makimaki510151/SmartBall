# スマートボール

ブラウザで遊べる、横モノのスマートボールです。GitHub Pagesに置いて、そのまま開けます。

寝かせた盤面に玉を一球ずつ打ち、穴へ入れると玉が増えます。実在の営業や現金の賭けではなく、玉を使うとブラウザの中の帳面が一行ずつ開きます。

## 遊び方

1. 「100円投入」で玉が25個出ます。最初の持ち金は1000円です。
2. 盤面右の赤いレバーを下に引いて離します。強いほど玉は左へ落ちます。
3. 穴は落ちやすくしてあります。右の安定穴は5球、中央の大穴は15球です。
4. 上のS（スタートチャッカー）を通すと役物が開き、開いた穴に入ると15球。入った口は閉じます。
5. 「連」の穴は左右そろってはじめて払い出されます。
6. 入賞が続くとフィーバーになり、払い出しが増えます。40球ごとにサービス玉が出ます。
7. 持ち玉は盤面の下の受け皿に、玉そのものとして積まれます。「玉を眺める」で山を傾けて見られます。山が高くなったら「箱にしまう」と、箱の窓に移ります。
8. 「物語」で、持ち玉を払って帳面を一行ずつ読みます。一行は短く、全部で約十万球です。玉も持ち金もなくなったら、店主が100円貸してくれます。

スペースキーの長押し、または↓キーでもレバーになります。Enterで「同じ力で打つ」。全体・BGM・効果音の音量は右側のつまみです。

ゲージの白線は前回の強さを覚えています。同じ力で続けて打つと、レールが滑って落ち口が左右にずれます。

## 動かし方

依存パッケージはありません。

```bash
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765` を開きます。

## GitHub Pages

リポジトリの Settings → Pages で、公開ブランチのルート（`/`）を指定してください。`index.html` がトップになり、パスはすべて相対です。
